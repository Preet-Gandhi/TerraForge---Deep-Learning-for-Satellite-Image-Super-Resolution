# TerraForge

### AI-Powered Satellite Image Super-Resolution

> **Deep learning framework for transforming medium-resolution satellite imagery into sharper, information-rich products while preserving geospatial and spectral consistency.**

TerraForge explores deep learning-based **Super-Resolution Mapping (SRM)** for Earth observation imagery. The system takes **10 m Sentinel-2 satellite imagery** and aims to reconstruct fine-scale spatial information to produce enhanced products at **<4 m resolution**.

The goal isn't simply to make satellite images *look sharper*. TerraForge focuses on reconstructing useful spatial details while maintaining the underlying **geographic and spectral integrity** of the original imagery.

### What TerraForge aims to support

* **Satellite Image Super-Resolution**
* **Agricultural & Crop Monitoring**
* **Urban Mapping & Analysis**
* **Environmental Monitoring**
* **Disaster Assessment**
*  **Fine-Scale Feature Detection**
* **Uncertainty-Aware Validation**

The framework is designed around the complete pipeline — from **pre-processing and model training** to **super-resolution inference, accuracy assessment, and validation against high-resolution reference imagery**.
